# Summary

IPAM allocates workload addresses according to a selected authority and pool model. Routing must then make those addresses reachable; allocation alone cannot establish connectivity.

Pool capacity, overlap, node allocation and cloud limits affect new endpoints. Different modes assign responsibilities differently, so lifecycle and migration decisions need the supported deployment contract rather than an arbitrary configuration switch on a running cluster.
