# IP Address Management (IPAM) with Cilium

This section covers iP Address Management (IPAM) with Cilium. It develops address Allocation, Pools And Routing Compatibility through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Explain allocation separately from route reachability.
- Compare Kubernetes-host-scope and Cilium-managed pool roles.
- Account for cloud-specific allocation and capacity limits.
- Diagnose exhaustion, overlap and incompatible mode changes.
