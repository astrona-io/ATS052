# Cilium Component Roles

This section covers cilium Component Roles. It develops agent, Operator, CNI And Hubble Responsibilities through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Assign endpoint and datapath responsibilities to the agent.
- Explain operator coordination and CNI lifecycle roles.
- Distinguish Hubble server, Relay, CLI and UI.
- Separate remote Cilium CLI access from node-local debug access.
