# Summary

Cilium supplies networking and related enforcement for Kubernetes workloads through node agents and a programmed datapath. Pod connectivity, Service translation and policy decisions remain distinct relationships.

Identity and Hubble add context for protection and observation. Optional routing, proxy, encryption and multi-cluster features require deliberate configuration; installing a network plugin alone does not establish every advertised capability or useful application behavior.
