# Datapath Models

This section covers datapath Models. It develops overlay And Native Routing Packet Paths through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains include an intermediate checkpoint before the final review.

## Learning Outcomes

- Trace encapsulated and native-routed cross-node traffic.
- Explain underlay reachability and Pod-prefix requirements.
- Relate MTU, masquerading and return paths to failures.
- Separate routing model from policy and encryption.
